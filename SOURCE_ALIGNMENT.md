# Source Alignment Note

The public documentation was drafted from the current MAYA EDA-Lite architecture described in the uploaded project README and from the current development direction established for MAYA Collector, EDA-Lite, MAYA Core and MAYA Hunter.

The attached EDA-Lite package describes:
- Collector-grounded CSV ingestion;
- explicit `-1` sentinel handling;
- WFO-Lite with dynamic purge;
- pooled Monte Carlo;
- robustness;
- economic evaluation;
- surrogate OOS fidelity;
- candidate registry;
- multiple-testing metadata.

This public blueprint deliberately distinguishes implemented behavior from planned/future behavior. It does not present the current research branch as production-ready.
