# GitHub Public Release Checklist

## Documentation

- [ ] README reviewed
- [ ] Architecture document reviewed
- [ ] Methodology reviewed
- [ ] Roadmap reviewed
- [ ] Status reviewed
- [ ] Limitations documented

## Research integrity

- [ ] Current implementation clearly separated from target architecture
- [ ] No unsupported profitability claims
- [ ] OOS boundaries documented
- [ ] Candidate status semantics documented

## Security

- [ ] No API keys
- [ ] No broker credentials
- [ ] No passwords
- [ ] No private infrastructure configuration

## Data

- [ ] No proprietary full historical datasets
- [ ] Public examples are licensed or synthetic
- [ ] Dataset provenance documented

## Engineering

- [ ] Tests included
- [ ] Reproducible setup documented
- [ ] Dependency file included
- [ ] .gitignore included
