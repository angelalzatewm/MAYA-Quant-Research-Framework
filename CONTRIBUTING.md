# Contributing to MAYA

MAYA is currently a research project.

## Before contributing

Please preserve:

- temporal separation;
- causal feature availability;
- reproducibility;
- explicit contracts;
- tests for changed modules.

## Research changes

Any change to:

- labels;
- time boundaries;
- feature definitions;
- validation;
- Monte Carlo;
- economics;
- candidate status

should include a short methodological note explaining the impact.

## Pull requests

A useful pull request should state:

```text
Problem
Change
Why
Research impact
Tests
Known limitations
```
